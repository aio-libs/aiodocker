Fixed the registry host sent in the `X-Registry-Auth` header by `images.pull()` and `images.push()`. The host was taken as everything before the first slash, so an authenticated pull of a Docker Hub image such as `homeassistant/base` announced the `homeassistant` namespace as the server address, which Docker's containerd image store rejects as a host mismatch. The domain is now resolved the way Docker resolves it, so a reference without a registry, or one naming `docker.io` or `index.docker.io`, authenticates against the default registry. A reference without a slash, such as `nginx`, no longer raises `ValueError` when auth is provided.
