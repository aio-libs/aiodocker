Raise the minimum required ``aiohttp`` to ``>=3.11.13``. Earlier releases contain a ``break`` inside a ``finally`` block in ``aiohttp/web_protocol.py`` which Python 3.14 turns into a ``SyntaxWarning`` under PEP 765; the offending code was fixed in aiohttp 3.11.13 (aio-libs/aiohttp#10434, backported in #10476). The 3.10 series is end-of-life. The CI test matrix now exercises ``aiohttp~=3.11.0`` and ``aiohttp~=3.13.0`` instead of 3.10 and 3.13.
