Default ``images.pull()`` to the ``"latest"`` tag when neither a ``tag`` argument nor an embedded tag/digest in ``from_image`` is provided, matching the behavior of the ``docker pull`` CLI. Previously the Docker Engine interpreted the missing tag as "pull all tags", which failed for repositories whose historical tags lack manifests for the host architecture (notably on arm64). Callers that relied on the previous all-tags behavior must now pass ``tag=""`` explicitly.
