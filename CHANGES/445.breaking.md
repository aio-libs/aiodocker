``images.push()``, ``images.pull()``, ``images.build()``, and ``images.import_image()`` now raise ``DockerStreamError`` when the Docker Engine reports an error in the progress stream, instead of silently returning the error chunk as part of the response. Existing ``except DockerError`` blocks continue to catch these failures because ``DockerStreamError`` is a subclass. Callers that intentionally inspected the returned list for an ``error`` key must update their code to catch the exception instead.
