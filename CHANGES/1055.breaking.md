`images.pull()` and `images.push()` no longer raise `ValueError` when `auth` is provided and the reference does not contain a slash. Such a reference, for example `nginx`, is a Docker Hub image and now authenticates against the default registry instead of being rejected. `ValueError` is still raised for an empty reference. Callers relying on the previous error to detect a missing registry address must check the reference themselves, for instance with the newly exported `split_docker_domain()`.
